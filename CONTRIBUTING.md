# Contributing

Thanks for contributing to Science Whiteboard.

## Workflow

1. Create a feature branch from `main`.
2. Keep changes focused and small.
3. Test the whiteboard in a modern Chromium/Firefox browser.
4. Use clear commit messages.
5. Open a pull request with a short summary and testing notes.

## Conventions

- Use semantic, descriptive names for functions and files.
- Preserve RTL and Arabic usability.
- Avoid unnecessary dependencies.
- Keep the MVP lightweight and browser-first.

## Commit examples

- `feat: add arrow drawing tool`
- `fix: preserve canvas state after zoom`
- `docs: update setup instructions`
